# My agent: Smart Real Estate Finder
One-liner: A conversational agent that helps home seekers discover, evaluate, and visualize properties with a catalog of curated real estate listings.

Tool coverage:
- Memory: Remembers buyer preferences across sessions (budget, target neighborhoods, bedroom/bathroom count, pet-friendliness, commute preferences, and favorited/rejected properties).
- Tools: Property search and filter (price range, neighborhood, home type, amenities), tour scheduling, and neighborhood metrics lookup (walk score, schools, transit).
- Catalog/UI: Collection of real estate listings rendered as rich property cards (price, specs, address, photo, key highlights) and side-by-side comparison tables.
- Image gen: Generates interior staging, room redesign, and exterior remodeling visualizations based on property spaces.
- Sandbox: Python calculations for monthly mortgage payments (PITI), loan amortization schedules, property tax estimates, and price-per-square-foot comparisons.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for financial and mortgage calculations, Google Maps Places API for neighborhood points of interest, Cloud Trace for observability
